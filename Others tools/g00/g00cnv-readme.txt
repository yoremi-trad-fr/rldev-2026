                   Convertisseur de fichiers g00 pour Windows  Rel.1

                                                   http://d4.princess.ne.jp/

---------------------------------------------------------------- ------------


[1] Introduction
  Ce logiciel permet de convertir les fichiers g00 utilisés dans CLANNAD.
  Une fois convertis, les fichiers peuvent être extraits sous forme d'images.
  Les images semi-transparentes peuvent être exportées au format Photoshop (.psd).

[2] Contenu de l'archive
      g00cnv.exe     Fichier principal
      readme.txt     Ce fichier

【３】Mode d'emploi
  Dans « Select convert file », sélectionnez le fichier pdt à convertir.
   Vous pouvez sélectionner plusieurs fichiers, mais si vous en sélectionnez un grand nombre (plus de 2000 environ),
   une erreur se produira et la conversion échouera.
   Dans « Output folder », sélectionnez le dossier de destination.
   Une fois les paramètres définis, cliquez sur le bouton « convert » pour lancer la conversion.
  Si la case « Output in psd » est cochée (par défaut), les images semi-transparentes seront converties au format psd.
 Si la case n'est pas cochée, toutes les images seront converties au format bmp.

[4] Explications supplémentaires
  ・Si vous décochez la case « Output in psd » avant la conversion, les images bmp obtenues présenteront des zones où la couleur devrait être semi-transparente
  transparentes. En effet, les informations de transparence sont complètement ignorées, ce qui fait que même les couleurs proches de la transparence s'affichent clairement.
  Nous vous recommandons donc d'exporter les images semi-transparentes au format psd.
  ・Le traitement des erreurs est quasi inexistant. Par conséquent, le programme risque de ne pas fonctionner correctement si vous essayez d'importer des fichiers non pris en charge ou si l'espace disque est insuffisant.
  ・Les fichiers psd ne comportant que des calques et des calques fusionnés ne s'affichent pas sous forme de vignettes dans l'explorateur, etc.
  ・Les fichiers psd ne créant que des calques et des calques fusionnés, les vignettes ne s'affichent pas dans l'Explorateur, par exemple.
  Si cela vous gêne, veuillez les enregistrer à nouveau à l'aide du traitement par lots de Photoshop, par exemple.
  ・Les fichiers g00 semblent avoir la notion de calque, mais tous les calques sont exportés sous la forme d'une seule image fusionnée.


[6] Autres
  Le fonctionnement a été vérifié avec la version CLANNAD pour tous les âges.
